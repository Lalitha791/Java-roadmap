# Core Java – Day 2: Type Casting, Constants & Type Promotion

This repository contains beginner-friendly Java examples and practice tasks for Day 2 of the Core Java learning roadmap.

## Topics
1. Widening (implicit) casting
2. Narrowing (explicit) casting
3. Converting `double` to `int`
4. Converting `int` to `double`
5. The `final` keyword
6. Type promotion in expressions
7. Gross salary calculation

## How to run
Open a terminal in the folder containing a `.java` file, then run:
```bash
javac WideningExample.java
java WideningExample
```
For files declared with a public class, the filename must match the class name.
