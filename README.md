# Complete 90-Day Infosys Mysore SE Preparation Roadmap

# Core Java + DSA

90 days

Beginner to assessment-ready

2 hours daily

This roadmap focuses on Core Java, problem-solving, DSA, coding assessments and technical interviews. We will progress topic by topic without skipping fundamentals.

## Overall roadmap

# 90 days at a glance

Phase 1 – Core Java

Days 1–30

Java fundamentals, OOP and advanced Java.

Phase 2 – DSA Foundations

Days 31–60

Complexity, searching, sorting, arrays, strings and patterns.

Phase 3 – Advanced DSA

Days 61–90

Linked lists, stacks, queues, hashing, trees, greedy and DP.

# Phase 1 – Core Java (Days 1–30)

Goal: Become comfortable writing Java programs independently.

## Module 1: Java fundamentals (Days 1–10)

| Day | Topic                    | What you will learn                                                     |
| --- | ------------------------ | ----------------------------------------------------------------------- |
| 1   | Introduction to Java     | JDK, JRE, JVM, bytecode, program structure, main method                 |
| 2   | Variables and data types | Primitive/reference types, casting, widening, narrowing, final          |
| 3   | Operators                | Arithmetic, relational, logical, assignment, unary, ternary, precedence |
| 4   | Conditional statements   | if, if-else, else-if, nested if                                         |
| 5   | Switch statement         | switch, case, break, default, fall-through                              |
| 6   | Loops – Part 1           | for loop, while loop, do-while                                          |
| 7   | Loops – Part 2           | Nested loops, break, continue                                           |
| 8   | Pattern programming      | Star, number, pyramid patterns                                          |
| 9   | Methods                  | Parameters, return types, method calling, overloading                   |
| 10  | Revision and assessment  | Java fundamentals test and coding assessment                            |

## Module 2: Arrays and methods (Days 11–15)

| Day | Topic                        | What you will learn                                   |
| --- | ---------------------------- | ----------------------------------------------------- |
| 11  | Arrays – Part 1              | Declaration, initialization, traversal                |
| 12  | Arrays – Part 2              | Sum, average, max, min, second largest                |
| 13  | 2D arrays                    | Matrix input, output, addition, transpose             |
| 14  | Searching and sorting basics | Linear search, bubble sort, selection sort            |
| 15  | Recursion basics             | Base condition, recursive calls, factorial, Fibonacci |

## Module 3: Strings (Days 16–20)

| Day | Topic                          | What you will learn                                          |
| --- | ------------------------------ | ------------------------------------------------------------ |
| 16  | String fundamentals            | Creation, immutability, comparison                           |
| 17  | String methods                 | length, charAt, substring, equals, split                     |
| 18  | StringBuilder and StringBuffer | Mutable strings and common operations                        |
| 19  | String coding problems         | Reverse, palindrome, vowels, character frequency             |
| 20  | String assessment              | Anagram, duplicate characters, first non-repeating character |

## Module 4: Object-Oriented Programming (Days 21–26)

| Day | Topic                      | What you will learn                                   |
| --- | -------------------------- | ----------------------------------------------------- |
| 21  | Classes and objects        | Fields, methods, object creation                      |
| 22  | Constructors               | Default, parameterized, constructor overloading, this |
| 23  | Encapsulation              | Private fields, getters, setters                      |
| 24  | Inheritance                | extends, super, types of inheritance                  |
| 25  | Polymorphism               | Overloading, overriding, runtime polymorphism         |
| 26  | Abstraction and interfaces | Abstract classes, interfaces, implements              |

## Module 5: Advanced Core Java (Days 27–30)

| Day | Topic                  | What you will learn                                                  |
| --- | ---------------------- | -------------------------------------------------------------------- |
| 27  | Exception handling     | try, catch, finally, throw, throws                                   |
| 28  | Collections – Part 1   | ArrayList, LinkedList, List, Set                                     |
| 29  | Collections – Part 2   | HashMap, HashSet, TreeSet, Iterator                                  |
| 30  | Advanced Java revision | Generics, wrapper classes, Java 8 lambda, streams basics, assessment |

Phase 1 target

- Write basic Java programs without copying.
- Understand OOP concepts.
- Solve approximately 30–40 Core Java problems.

# Phase 2 – DSA Foundations (Days 31–60)

Goal: Learn how to solve coding problems efficiently.

## Module 6: DSA foundations (Days 31–35)

| Day | Topic               | What you will learn                             |
| --- | ------------------- | ----------------------------------------------- |
| 31  | Introduction to DSA | Data structures, algorithms, problem-solving    |
| 32  | Time complexity     | Big O, O(1), O(n), O(log n), O(n²)              |
| 33  | Space complexity    | Auxiliary space, memory usage                   |
| 34  | Recursion practice  | Factorial, Fibonacci, sum of digits             |
| 35  | Recursion problems  | Reverse number, power, recursive array problems |

## Module 7: Searching and sorting (Days 36–40)

| Day | Topic                        | What you will learn                  |
| --- | ---------------------------- | ------------------------------------ |
| 36  | Linear search                | Searching elements in arrays         |
| 37  | Binary search                | Binary search and its variations     |
| 38  | Sorting algorithms           | Bubble, selection and insertion sort |
| 39  | Advanced sorting             | Merge sort and quick sort            |
| 40  | Searching/sorting assessment | Mixed coding problems and complexity |

## Module 8: Arrays (Days 41–47)

| Day | Topic                        | What you will learn              |
| --- | ---------------------------- | -------------------------------- |
| 41  | Array basics revision        | Traversal, insertion, deletion   |
| 42  | Array problems               | Reverse, rotate, duplicates      |
| 43  | Missing and repeated numbers | Missing number, duplicate number |
| 44  | Two Sum                      | Pair sum and variations          |
| 45  | Prefix sums                  | Range sum and cumulative sums    |
| 46  | Kadane's algorithm           | Maximum subarray sum             |
| 47  | Array assessment             | Mixed timed coding test          |

## Module 9: Strings (Days 48–52)

| Day | Topic                  | What you will learn                       |
| --- | ---------------------- | ----------------------------------------- |
| 48  | String problem-solving | Reverse, palindrome, anagram              |
| 49  | Frequency problems     | Character counts and duplicates           |
| 50  | String manipulation    | Remove spaces, reverse words              |
| 51  | Advanced strings       | Longest common prefix, substring problems |
| 52  | String assessment      | Mixed coding questions                    |

## Module 10: Two pointers and sliding window (Days 53–60)

| Day | Topic                   | What you will learn                            |
| --- | ----------------------- | ---------------------------------------------- |
| 53  | Two pointers – Part 1   | Opposite-direction pointers                    |
| 54  | Two pointers – Part 2   | Pair sum, remove duplicates                    |
| 55  | Sliding window – Part 1 | Fixed-size window                              |
| 56  | Sliding window – Part 2 | Variable-size window                           |
| 57  | Maximum sum subarray    | Window-based problems                          |
| 58  | Longest substring       | Longest substring without repeating characters |
| 59  | Mixed DSA practice      | Arrays, strings, pointers                      |
| 60  | DSA assessment          | Timed coding test and revision                 |

Phase 2 target

- Understand basic time and space complexity.
- Solve approximately 50–60 DSA problems cumulatively.
- Recognize common problem-solving patterns.

# Phase 3 – Advanced DSA (Days 61–90)

Goal: Prepare for more challenging coding assessments and technical interviews.

## Module 11: Linked lists (Days 61–65)

| Day | Topic                    | What you will learn                 |
| --- | ------------------------ | ----------------------------------- |
| 61  | Linked list introduction | Nodes, head, pointers               |
| 62  | Insertion                | Insert at beginning, end, position  |
| 63  | Deletion                 | Delete nodes and search             |
| 64  | Linked list problems     | Reverse, middle element             |
| 65  | Advanced linked lists    | Cycle detection, merge sorted lists |

## Module 12: Stacks and queues (Days 66–70)

| Day | Topic              | What you will learn                    |
| --- | ------------------ | -------------------------------------- |
| 66  | Stack fundamentals | Push, pop, peek                        |
| 67  | Stack problems     | Balanced parentheses                   |
| 68  | Advanced stack     | Next greater element                   |
| 69  | Queue fundamentals | Enqueue, dequeue, circular queue       |
| 70  | Queue problems     | Queue using stacks, stack using queues |

## Module 13: Hashing (Days 71–74)

| Day | Topic               | What you will learn                 |
| --- | ------------------- | ----------------------------------- |
| 71  | HashMap and HashSet | Hashing fundamentals                |
| 72  | Frequency counting  | Element and character frequency     |
| 73  | Hashing problems    | Two Sum, duplicates, group anagrams |
| 74  | Subarray problems   | Subarray sum equals K               |

## Module 14: Trees and heaps (Days 75–81)

| Day | Topic                    | What you will learn                |
| --- | ------------------------ | ---------------------------------- |
| 75  | Binary trees             | Nodes, root, leaf                  |
| 76  | Tree traversal           | Inorder, preorder, postorder       |
| 77  | Tree problems            | Height, depth, node count          |
| 78  | Binary Search Trees      | Insert, search, delete concepts    |
| 79  | BST problems             | Validate BST, minimum and maximum  |
| 80  | Heaps                    | Min heap, max heap, priority queue |
| 81  | Tree and heap assessment | Mixed problems                     |

## Module 15: Greedy and Dynamic Programming (Days 82–86)

| Day | Topic                            | What you will learn                    |
| --- | -------------------------------- | -------------------------------------- |
| 82  | Greedy algorithms                | Greedy approach and activity selection |
| 83  | Greedy problems                  | Coin change basics, interval problems  |
| 84  | Dynamic programming introduction | Overlapping subproblems, memoization   |
| 85  | DP problems                      | Fibonacci, climbing stairs             |
| 86  | DP basics                        | Tabulation and introductory knapsack   |

## Module 16: Final assessment preparation (Days 87–90)

| Day | Topic                    | What you will do                                      |
| --- | ------------------------ | ----------------------------------------------------- |
| 87  | Core Java revision       | Output questions, OOP, exceptions, collections        |
| 88  | DSA revision             | Arrays, strings, searching, sorting                   |
| 89  | Mock assessment          | Timed mixed coding assessment                         |
| 90  | Final mock and interview | Coding test, debugging, technical interview questions |

Phase 3 target

- Solve linked list, stack, queue, hashing and tree problems.
- Understand basic greedy and DP patterns.
- Complete timed assessments independently.
