# Day 3 Assignments – Operators

Write each program yourself. Use `Scanner` for input where appropriate.

1. Read two integers and print their sum, difference, product, quotient and remainder.
2. Read an integer and check whether it is even or odd using `%`.
3. Read a number and check whether it is divisible by both 5 and 3.
4. Read two numbers and print the larger using the ternary operator.
5. Read three numbers and print the largest.
6. Read an integer and print its last digit using `% 10`.
7. Swap two numbers using a temporary variable.
8. Predict and then verify the output of prefix and postfix increment/decrement expressions.
9. Read age and marks. Print eligible only if age is at least 18 and marks are at least 60.
10. Evaluate an arithmetic expression and explain the operator precedence.

## Extra challenge
Read the price of a product and a discount percentage. Calculate the discount amount and final price. Print both with two decimal places using `printf`.
