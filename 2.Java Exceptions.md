# Java Exceptions

## 1. What is an Exception?

An **exception** is an unexpected event that occurs while a program is running and interrupts its normal execution.

**Example:** Dividing a number by zero.

```java
int result = 10 / 0;
```

This causes an `ArithmeticException`.

- **Throwing an exception:** Raising an exception when a problem occurs.
- **Catching an exception:** Handling the problem so the program can respond properly.

## 2. Java Exception Hierarchy

Java provides a hierarchy for handling errors and exceptions.

```text
              Throwable
              /       \
        Exception      Error
           |
     RuntimeException
```

### Main categories

| Type | Meaning | Example |
|---|---|---|
| Checked Exception | Checked by the compiler | IOException |
| Unchecked Exception | Occurs at runtime; compiler does not require handling | NullPointerException |
| Error | Serious JVM or system-level problem | OutOfMemoryError |

## 3. Checked Exceptions

Checked exceptions are checked at **compile time**.

We must either:
- Handle them using `try-catch`.
- Declare them using `throws`.

Examples:

| Exception | Meaning |
|---|---|
| IOException | Input/output problem |
| FileNotFoundException | File does not exist |
| SQLException | Database problem |
| ClassNotFoundException | Class cannot be found |
| InterruptedException | Thread was interrupted |

## 4. Unchecked Exceptions

Unchecked exceptions occur during program execution. The compiler does not force us to handle or declare them.

They inherit from `RuntimeException`.

| Exception | Meaning |
|---|---|
| ArithmeticException | Invalid arithmetic operation, such as integer division by zero |
| NullPointerException | Accessing something through a null reference |
| ArrayIndexOutOfBoundsException | Accessing an invalid array index |
| NumberFormatException | Converting invalid text into a number |
| IllegalArgumentException | Passing an invalid argument |

## 5. Difference Between Checked and Unchecked Exceptions

| Checked | Unchecked |
|---|---|
| Checked at compile time | Occurs at runtime |
| Must catch or declare | Catching or declaring is optional |
| Usually external problems | Often programming mistakes or invalid inputs |
| IOException | NullPointerException |

## 6. Important Exception Keywords

### `try`
Contains code that might cause an exception.

### `catch`
Handles an exception raised inside the corresponding `try` block.

### `finally`
Normally executes whether an exception occurs or not. Commonly used for cleanup.

### `throw`
Explicitly raises an exception object inside a method or block.

Example syntax:

```java
throw new IllegalArgumentException("Invalid age");
```

### `throws`
Declares in a method signature that the method may pass an exception to its caller.

Example syntax:

```java
public void readFile() throws IOException {
    // File-reading code
}
```

**Remember:**

| throw | throws |
|---|---|
| Used to raise an exception | Used to declare possible exceptions |
| Followed by an exception object | Followed by exception class names |
| Used inside a method or block | Used in a method declaration |

## 7. How try-catch-finally Works

1. Java executes the `try` block.
2. If an exception occurs, Java looks for a matching `catch` block.
3. The matching `catch` handles the exception.
4. The `finally` block normally executes after the try/catch process.

**Important:** A `finally` block is not guaranteed if the JVM or process terminates abruptly.

## 8. Multiple Catch Blocks

We can use multiple `catch` blocks to handle different exceptions.

**Important rule:** Write specific exceptions before general exceptions.

For example:

```java
catch (ArithmeticException e) {
    // Handle arithmetic problem
}
catch (Exception e) {
    // Handle other exceptions
}
```

Writing `Exception` first would make the later specific catch unreachable.

## 9. Custom Exceptions

Java allows us to create our own exception classes.

Two common choices:

- `extends Exception` – Creates a checked custom exception.
- `extends RuntimeException` – Creates an unchecked custom exception.

The `super(message)` statement passes the error message to the parent exception class.

## 10. Exception vs Error

| Exception | Error |
|---|---|
| Problems an application may handle | Serious system/JVM problems |
| Can often be recovered from | Usually difficult to recover from |
| Can be checked or unchecked | Generally unchecked |
| IOException | OutOfMemoryError |

Examples of errors:
- OutOfMemoryError
- StackOverflowError
- VirtualMachineError
- NoClassDefFoundError

Both `Exception` and `Error` inherit from `Throwable`.

# Exercism Exercise: Calculator Conundrum

## 11. Problem Understanding

Create a calculator that accepts:

- `operand1` – First number.
- `operand2` – Second number.
- `operation` – Mathematical operator.

Supported operations:

| Operator | Operation | Example |
|---|---|---|
| `+` | Addition | 16 + 51 = 67 |
| `*` | Multiplication | 16 * 2 = 32 |
| `/` | Division | 16 / 2 = 8 |

The method should return the calculation as a formatted String.

## 12. Conditions to Handle

| Condition | Expected behavior |
|---|---|
| Operation is `null` | Throw IllegalArgumentException |
| Operation is empty (`""`) | Throw IllegalArgumentException |
| Operation is `+` | Perform addition |
| Operation is `*` | Perform multiplication |
| Operation is `/` | Perform division |
| Unsupported operation | Throw IllegalOperationException |
| Division by zero | Throw IllegalOperationException with ArithmeticException as its cause |

## 13. Important Concepts Used in This Exercise

**1. String comparison**

Use `.equals()` to compare String values.

```java
operation.equals("+")
```

Do not use `==` for comparing String contents.

**2. Checking null**

```java
operation == null
```

Check for null before calling methods such as `.isEmpty()`.

**3. Checking empty String**

```java
operation.isEmpty()
```

An empty String contains no characters.

**4. Exception chaining**

When one exception is caused by another, we can preserve the original exception as the cause.

```java
throw new IllegalOperationException("Division by zero is not allowed", e);
```

Here, `e` is the original `ArithmeticException`.

**5. Custom exception**

`IllegalOperationException` is the exception required by this exercise. Exercism may provide this class in its starter files. If it does, do not create another class with the same name.

# 16. Complete Java Code

### CalculatorConundrum.java

```java
public class CalculatorConundrum {

    public String calculate(int operand1, int operand2, String operation) {

        if (operation == null) {
            throw new IllegalArgumentException("Operation cannot be null");
        }

        if (operation.isEmpty()) {
            throw new IllegalArgumentException("Operation cannot be empty");
        }

        int result;

        try {

            if (operation.equals("+")) {
                result = operand1 + operand2;

            } else if (operation.equals("*")) {
                result = operand1 * operand2;

            } else if (operation.equals("/")) {
                result = operand1 / operand2;

            } else {
                throw new IllegalOperationException(
                    "Operation '" + operation + "' does not exist"
                );
            }

        } catch (ArithmeticException e) {

            throw new IllegalOperationException(
                "Division by zero is not allowed", e
            );
        }

        return operand1 + " " + operation + " " + operand2 + " = " + result;
    }
}
```

```java
public class IllegalOperationException extends RuntimeException {

    public IllegalOperationException(String message) {
        super(message);
    }

    public IllegalOperationException(String message, Throwable cause) {
        super(message, cause);
    }
}
```

**Expected outputs for valid operations:**

| Input | Output |
|---|---|
| `16, 51, "+"` | `16 + 51 = 67` |
| `16, 2, "*"` | `16 * 2 = 32` |
| `16, 2, "/"` | `16 / 2 = 8` |

public class CalculatorConundrum {

    public String calculate(int operand1, int operand2, String operation) {

        if (operation == null) {
            throw new IllegalArgumentException("Operation cannot be null");
        }

        if (operation.isEmpty()) {
            throw new IllegalArgumentException("Operation cannot be empty");
        }

        int result;

        try {
            switch (operation) {

                case "+":
                    result = operand1 + operand2;
                    break;

                case "*":
                    result = operand1 * operand2;
                    break;

                case "/":
                    result = operand1 / operand2;
                    break;

                default:
                    throw new IllegalOperationException(
                        "Operation '" + operation + "' does not exist"
                    );
            }

        } catch (ArithmeticException e) {

            throw new IllegalOperationException(
                "Division by zero is not allowed", e
            );
        }

        return operand1 + " " + operation + " " + operand2 + " = " + result;
    }
}
